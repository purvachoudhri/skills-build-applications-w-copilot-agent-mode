# OctoFit Tracker

## Overview
The OctoFit Tracker is a fitness application designed to help users track their activities, manage teams, and receive personalized workout suggestions. The app includes user authentication, activity logging, and a competitive leaderboard to enhance user engagement.

## Project Structure
The project is organized into two main directories: `backend` and `frontend`.

### Backend
- **venv/**: Contains the Python virtual environment for the OctoFit Tracker app, isolating all necessary packages and dependencies.
- **octofit_tracker/**: This directory holds the main application code, including Django models, views, and other components essential for the app's functionality.
- **requirements.txt**: Lists the required Python packages for the project, ensuring that the correct versions are installed.

### Frontend
- **frontend/**: This directory is designated for the frontend part of the OctoFit Tracker app, which will manage the user interface and client-side logic.

## Setup Instructions

### Backend Setup
1. **Create a Python Virtual Environment**
   Navigate to the `backend` directory and run the following command:
   ```
   python3 -m venv venv
   ```

2. **Activate the Virtual Environment**
   ```
   source venv/bin/activate
   ```

3. **Install Required Packages**
   Ensure you have the `requirements.txt` file in the `backend` directory, then run:
   ```
   pip install -r requirements.txt
   ```
